# HotelSite

HTML ve CSS kullanılarak hazırlanmış basit bir statik otel web sitesi şablonu. Site; ana sayfa, hizmetler, galeri, oda listesi, ekip bölümü, iletişim formu ve ayrı bir blog sayfası içerir.

## Dosya Yapısı

- `index.html` – Ana otel sayfası
- `blogs.html` – Blog sayfası
- `css/style.css` – Proje stil dosyası
- `css/utils.css` – Yardımcı CSS sınıfları
- `img/` – Web sitesinde kullanılan görseller

## Özellikler

- Duyarlı (responsive) ana sayfa düzeni
- Hizmetler, hakkında, galeri, odalar, ekip ve iletişim bölümleri
- Basit iletişim formu
- Font Awesome ikonlarıyla zengin görsel içerik

## Kullanım

1. Proje klasörünü açın.
2. `index.html` dosyasını tarayıcınızda açın.
3. `blogs.html` sayfasını ziyaret ederek blog içeriğini görüntüleyin.

## Özelleştirme

- Metin ve içerikleri `index.html` ve `blogs.html` dosyalarında düzenleyin.
- Renkler, düzen ve animasyonlar için `css/style.css` ve `css/utils.css` dosyalarını değiştirin.
- Yeni resimler eklemek için `img/` klasörünü kullanın.

## Notlar

Bu proje tamamen statik bir HTML/CSS sitesidir; herhangi bir sunucu tarafı kodu veya backend gerektirmez.
